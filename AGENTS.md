# Study-manual production

Read docs/manual-standard.md before editing any manual or generator. Preserve canonical lesson/answer IDs, sources, historical files, and the separate exam reference. Use shared style components instead of per-lesson styling. A successful compile is not visual approval: render and inspect every changed PDF page, validate references, and record actual checks and limits. Build candidates separately and retain the previously approved PDFs until verification finishes. Do not change scientific or event-rule claims merely to fit a layout.
