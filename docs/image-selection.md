# Selecting identification photographs

Use this process for any event that asks students to recognize real specimens. The objective is a small, teachable set, not the most attractive photograph or the largest collection.

1. **Map the current rules.** List the required identification categories at the required taxonomic level. For broad categories, list the major forms students must recognize. Keep rules scope separate from examples.
2. **Define the job of each image.** Start with a clear diagnostic view. Add only a useful new view, life stage, color phase, growth form, or confusion-pair comparison. A second nearly identical photograph adds little. Use real photographs, not generated organisms.
3. **Search beyond the first result.** Search common and scientific names, diagnostic features and life stages. Compare several plausible candidates, including the current selection. Check institutional collections (for example NOAA), freely licensed photographer collections and observation archives. Commons is a useful index, not proof of identity or permission. An attractive copyrighted image can inform the search but cannot be copied without permission.
4. **Check identity and rights separately.** Read the individual source page and its upstream source when available. Confirm creator, license, attribution and modification requirements. Preserve uncertain identifications at the level supported by the source; do not infer an exact species from appearance alone. Federal hosting does not automatically make third-party photographs public domain. Exclude unclear rights, noncommercial-only and no-derivatives assets from the freely reusable collection unless a separate approved arrangement covers them.
5. **Inspect actual pixels.** Compare the diagnostic features, focus, angle, occlusion, misleading lighting, background, scale and useful resolution. Look at the full image and the proposed printed/screen size. Do not equate pixel count, a quality badge or a search rank with teaching value. Do not infer length from an unscaled photograph.
6. **Select and explain.** Retain a strong existing photo when alternatives add nothing. Captions should name the visible evidence and any meaningful limitation, not just the organism. Use variation to teach stable structure rather than memorizing color. Include unlabeled practice with explanatory feedback and comparison against plausible confusions.
7. **Preserve and build.** Keep a useful full-resolution source master, exact source/creator/license URLs and download hash. Use the project's reversible JPEG XL archive for JPEG originals or lossless archive for other rasters; update the technical master manifest and canonical rights record; link teaching data by source ID and regenerate notices (see [provenance.md](provenance.md)). Generate PDF and web derivatives independently. Preserve the license of each photograph and state resizing/re-encoding. Never alter diagnostic anatomy to improve the picture.
8. **Verify the result.** Check image/caption/answer correspondence, credits, asset paths and practice coverage. Render and inspect every changed PDF page and affected web view, including grayscale and identification detail after compression. Record any browser/physical-print checks that were not performed. Test learning with unfamiliar images before claiming educational effectiveness.

Keep one short event-specific selection record: date, categories reviewed, meaningful candidates and source links, retain/add/replace/reject decisions and reasons, and remaining gaps. Record actual search breadth, not an invented number of images considered. A targeted search can establish a useful improvement, not that the selected image is the best available anywhere.
