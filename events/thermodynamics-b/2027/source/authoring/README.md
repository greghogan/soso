# Authoring provenance

The JSON files in the parent source directory are canonical and include subsequent editorial and scientific corrections. These retained initial authoring scripts document generation history; do not run them over canonical files without reviewing the differences. Final JSON has spacing, captions, source mapping and construction pattern edits.

The active generator in [source/diagrams](../diagrams/) reproduces only the SVGs that matched the approved drawings exactly. The manually finalized diagrams remain editable SVG masters in `assets/diagrams/`; in particular, the final blackbody SVG uses corrected non-crossing Planck-shaped curves. All figures are original vector illustrations. No experimental performance is claimed.
