Solar System B 2027 — portable study guide

Extract this ZIP first. Open index.html in a current browser. Keep the extracted folder together. No installation, server, account or internet connection is required for the guide. Optional bibliography links need internet access. The printable PDF is delivered separately and is not needed to use this web bundle.

All text, images, diagrams, CSS and JavaScript are included locally. This release uses original interactive models rather than streaming video. Native answer disclosures work without JavaScript; interactive sliders require it.

Tested through a local HTTP preview. Direct file:// opening could not be exercised in the browser QA tool (HTTP/S-only policy); dependencies and relative links were checked independently.

This is independent study material, not an official Science Olympiad publication. Use the official rules and tournament clarifications for competition requirements. See ATTRIBUTION.txt for media notes. Editable sources and prompts are supplied separately, not needed by readers.
