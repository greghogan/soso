# Solar System B illustration provenance

Only the five illustrations used in the guides live in `assets/illustrations/`.
The cover, Titan, and small-bodies images are the scientifically reviewed
revisions; the worlds and rocky-worlds images still use their first-pass masters.

These records retain prompts, review notes and fingerprints for that artwork
and for the retired images. The detection-method and radiative-energy montages
are not used in the current guides, which teach those topics with editable
scientific diagrams and equations. Earlier paths and WebP names are historical
records, not required build inputs.
