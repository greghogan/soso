# Shared build fonts

These bundled DejaVu Sans 2.37 faces are the fallback for editable diagram
generators when the standard Docker-installed fonts are not present. The
regular, bold, and oblique files are unmodified copies from Debian
`fonts-dejavu-core` / `fonts-dejavu-extra` 2.37-8.
